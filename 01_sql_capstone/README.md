Capstone Project 2 — SQL
========================

What this practices
- LIKE and wildcards (% and _)
- DISTINCT
- WHERE filtering
- ORDER BY sorting
- Mixing those keywords in one query

How to run (SQLite)
  sqlite3 capstone.db < capstone.sql

Or open capstone.sql in DB Browser for SQLite / MySQL Workbench and run it.
Each SELECT is a separate practice question. Read the comment above it first.
